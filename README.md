# Dashboard-Daily
Uma dashboard que mostra clima, notícias e promoções, com atualizações constantes.
Essa aplicação está em desenvolvimento, sendo feita inteiramente em JavaScript com o uso do TailwindCSS.
Esse é meu primeiro contato com Tailwind CSS e estou gostando bastante. Inicialmente a Dashboard está funcionando com MOCKDATA mas futuramente vou integrá-la com APIs que fornecem os dados a serem mostrados.
O design é moderno e minimalista e em outro momento irei refinar mais esteticamente.
